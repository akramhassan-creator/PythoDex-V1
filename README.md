# PythoDex-V1

In order for this application to run, you must use the following:

CustomTkinter,

PokeBase API,

Matplotlib,

PANDAS

The commands for these pip installations are below:

pip install customtkinter,

pip install pokebase,

pip install matplotlib,

pip install pandas


If these commands give an error message or do not work, check your python directory, reinstall, or try these commands instead:


py -m pip install customtkinter,

py -m pip install pokebase,

py -m pip install matplotlib,

py -m pip install pandas

This isnt required but to match the Pokemon theme, i have incorprated a "Poke Font".


The link to the download for this font is here:


https://www.dafont.com/pokemon.font


Make sure to "Extract" the file and install *BOTH* fonts.
